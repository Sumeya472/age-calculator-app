# Age Calculator App
![Age Calculator App Preview](preview.jpg)

A responsive Age Calculator built as part of the [Frontend Mentor](https://www.frontendmentor.io/) challenges.

This application allows users to calculate their age in years, months, and days by entering their date of birth.

## Features

- Calculate age in years, months, and days.
- Validate day, month, and year inputs.
- Display error messages for empty or invalid fields.
- Highlight input borders and labels when validation errors occur.
- Prevent future dates from being submitted.
- Responsive design for mobile and desktop screens.

## Built With

- HTML5
- Tailwind CSS
- JavaScript
- Google Chrome / VS Code

## Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Sumeya472/age-calculator-app.git
   ```

2. Open the project folder:

   ```bash
   cd age-calculator-app
   ```

3. Open `index.html` in your browser or use the VS Code Live Server extension.
